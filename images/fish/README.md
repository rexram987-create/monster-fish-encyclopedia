# תמונות הדגים

23 המחשות שנוצרו עבור האתר בכלי image_gen ב־17.10.2026, בסגנון צילום טבע תיעודי. אלו אינן תמונות שצולמו בטבע ואינן תוצר או פרסום של National Geographic. ייתכנו אי־דיוקים אנטומיים; התמונות אינן מקור לזיהוי מדעי או למדידת גודל.

כל קובץ WebP נקרא לפי השם המדעי ומשויך לרשומה ב־data.js. התמונה של Myxocyprinus asiaticus מציגה פרט צעיר. הנחיות היצירה מופיעות ב־prompts.json.

התמונות נטענות מהמאגר ומוכללות במטמון ה־PWA בהתקנה. יש להשלים טעינה מקוונת לפני בדיקת שימוש ללא חיבור.
