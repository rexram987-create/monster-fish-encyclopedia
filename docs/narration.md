# הקראה בעברית

בחלון המידע של כל דג מופיעים כפתורי „הקראת המידע” ו„עצירת ההקראה”. אין הפעלה אוטומטית. ההקראה כוללת את פרטי הגודל, האטימולוגיה, התיעוד, התפוצה, התזונה, השימור, הסכנה והערות הבדיקה; קישורי מקורות אינם מוקראים.

סגירת החלון או מעבר לדג אחר מפסיקים את ההקראה. בדפדפן שאינו תומך בתכונה מופיעה הודעה. שגיאת הקראה מחזירה את הכפתורים למצב שמאפשר ניסיון נוסף.

היישום משתמש ב־Web Speech API ובקולות הזמינים במכשיר, עם העדפה לקול עברי מקומי. לא נוספו שירות הקראה בתשלום, מפתח API או קובצי הקלטה. ההגייה, ובפרט של שמות מדעיים, תלויה בקול המותקן.

עבודה ללא חיבור תלויה בזמינות קול עברי מקומי במכשיר. שמירת האתר והתמונות במטמון אינה מתקינה קול. איכות השמע ועבודה במצב טיסה דורשות בדיקה בטלפון.

אימות: `node --test` כולל בדיקות לרצף ההקראה, חלוקה למקטעים, בחירת קול עברי מקומי, מניעת התחלה אוטומטית, עצירה וביטול אירועים ישנים, חוסר תמיכה ושגיאת קול. הבדיקות משתמשות במנוע דיבור מדומה ואינן בודקות שמע בפועל.
